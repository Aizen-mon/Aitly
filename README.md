# AI Assistant for Tally Users

This repository contains a Flask backend and a Flutter frontend starter for an "AI Assistant for Tally Users" MVP. The assistant provides a chat-style interface and a dashboard, integrates with TallyPrime via XML API, and uses a rule-based NLP for intents.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the actual request flow, and backend/README.md and frontend/README.md for per-part instructions.
